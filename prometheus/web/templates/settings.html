One-time setup (about 10 minutes)
  1. Open console.cloud.google.com and make a new project called Prometheus.
  2. APIs & Services → Library: turn on Google Calendar API and Google Drive API.
  3. OAuth consent screen: External, app name Prometheus, your email; under Test users add your own Gmail.
  4. Credentials → Create credentials → OAuth client ID → Application type Desktop app.
  5. Copy the Client ID and Client secret into the boxes below, then press Sign in with Google.
