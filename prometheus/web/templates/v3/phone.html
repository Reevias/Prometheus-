2 · Android: the app

  1. Install Tailscale (Play Store) and sign in with the same account as the cloud copy.
  2. On the phone, open this page and press Download the app; Android asks once to allow installing from Chrome.
  3. Open Prometheus from its icon, press Open in the app (or type the address) and sign in.
  4. ☰ → Turn on phone notifications.

iPhone, or without the app

  1. Install Tailscale and sign in with the same account as the cloud copy.
  2. Scan the code (or type the address) and sign in with your Prometheus password.
  3. Chrome ⋮ → Add to home screen (iPhone: Safari → Share → Add to Home Screen).
  4. Open it from the icon → ☰ → Turn on phone notifications.

Optional: bank SMS into the money tracker, and letting Prometheus control the phone: Settings → Phone control and docs/phone-setup.md.
