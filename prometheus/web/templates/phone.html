Android: the Prometheus app (one download)

  1. Install Tailscale on the phone (Play Store) and sign in with the same account as the cloud copy.
  2. On the phone, open this page (scan the code above) and press Download the app. Open the file; Android asks once to allow installing from Chrome.
  3. Open Prometheus from its new icon. Press Open in the app below (or type the address), then sign in.
  4. ☰ → Turn on phone notifications.

iPhone, or without the app

  1. Install Tailscale and sign in with the same account as the cloud copy.
  2. Scan the code above (or type the address in the browser) and sign in with your Prometheus password.
  3. Chrome menu ⋮ → Add to home screen → Install. (iPhone: Safari → Share → Add to Home Screen.)
  4. Open it from the new icon → ☰ → Turn on phone notifications.

Optional: bank SMS into the money tracker (MacroDroid) and letting Prometheus control the phone (wireless debugging): Settings → Phone control, and docs/phone-setup.md.
