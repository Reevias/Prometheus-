Steps

  1. Install Tailscale on the phone (Play Store / App Store) and sign in with the same account as the cloud copy.
  2. Scan the code above (or type the address in Chrome) and sign in with your Prometheus password.
  3. Chrome menu ⋮ → Add to home screen → Install. (iPhone: Safari → Share → Add to Home Screen.)
  4. Open it from the new icon → ☰ → Turn on phone notifications.
  5. Optional: bank SMS into the money tracker (MacroDroid) and letting Prometheus control the phone (wireless debugging): Settings → Phone control, and docs/phone-setup.md.
