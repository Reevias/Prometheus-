# Prometheus: handoff for the next session

**What it is.** Prometheus is a personal multi-agent AI assistant ("a JARVIS") for one owner, running on their Windows laptop (8 GB RAM, no GPU; Android phone later). Repo: `github.com/Reevias/Prometheus-` (private), branch `main` (also mirrored to `claude/prometheus-v1-3`). Python 3.12+ (tested 3.12 and 3.14; CI runs 3.12/3.13/3.14 on Windows and Ubuntu), FastAPI + Jinja2 + htmx, SQLite (`memory.db`, WAL, FTS5), pywebview desktop window, installed with `scripts/install-windows.ps1` (clone first: the repo is private), `prometheus update` / nightly self-update. Data lives in `%LOCALAPPDATA%\Prometheus`; chats are also written to `%USERPROFILE%\Prometheus memory`. Version 1.4, ~650 tests (`python -m pytest -q`), all passing; the real-model voice tests run only with `PROMETHEUS_VOICE_MODELS` set.

**How it works.** A lead AI (the "brain", chosen in the chat header: Claude Opus/Sonnet/Haiku, OpenRouter, ~30 free providers from awesome-free-llm-apis, or local Ollama) plans each request as JSON (`answer`, `topic`, `title`, `remember`, `steps`) in `prometheus/orchestrator/planner.py`. Simple questions are answered directly; otherwise registered agents (`prometheus/agents/*`, `@register`, with `tools`, `required_inputs`, `private_outputs`, `accepts_private`, optional `verify()`) run the steps. The **planning loop** gives each failed step up to 3 tries (a different way proposed by the brain, never repeating), checks goals after actions (`verify`), and stops a task at $0.20 or 12 steps; successful repairs become **lessons** reused in later plans and in nightly learning. Agents: files (find/copy/move/rename/recycle/create incl. PDF with links and Word), file_sorter, documents (local model only), research, wikipedia, opener (well-known sites open freely), system (apps, windows, volume, Wi-Fi with password via Approvals, Bluetooth, power, Microsoft Store, install by name; app not installed → website + Install button → Store search), github (own repo with token; any public repo without it), obsidian, reminders (alarms, timers, standing goals), email (IMAP/SMTP app password), calendar (secret iCal link, read only), apps (any MCP server, stdio or HTTP), settings, guide (skills), repo_scout, antigravity. Memory: chats split by topic and chunked (FTS + optional Ollama embeddings), facts, saved pages/files, skills folders (`prometheus/skills/<name>/SKILL.md` + `references/`, user skills in `<data>/skills`, repo of the day adds approved trending repos), learned answer rules (`prompts/learned.md`, versioned in git, nightly from 👍/👎). Voice: always listening from Windows start ("Hello Prometheus"), Vosk trigger + Whisper base.en confirmation, Kokoro voice (Heart or Fable), "Yes sir" acknowledgement. Nightly at 23:30 (`daily.py`): learning, repo of the day, update. Watchers: battery, disk, CPU, folders. UI: graphite + red signal, dark/light, the orb (canvas), Outputs and Coming up panels, in-chat approvals.

**Rules that must hold.** Private data (files, notes, email, calendar, screenshots) is only read by local models unless the owner allows otherwise; cloud prompts get placeholders. Text from web pages, files, email and tools is wrapped with `untrusted()` and is never instructions. Approvals are two-tier: big things (installs, power, Wi-Fi, GitHub posts, sending email, cloning, self-edits, paid cloud jobs, repo of the day, big Recycle Bin batches) wait on the Approvals page; small ones (unfamiliar site or file, a click, Enter, model switch, MCP changes, installing an app you tried to open) are asked in the chat and remembered across chats (`Approvals.ask`, Settings → Always allowed). Never overwrite or delete (Recycle Bin, undo journal on History). Laptop commands are fixed PowerShell scripts with user values passed in environment variables, never in command text; terminals, script runners and admin tools are never opened. Secrets live in `<data>/.env` via `set_secret`, need the owner's password to change, are never logged or shown, and `safety/secrets.py` blocks keys in GitHub posts, self-edits and email. When `prompts/planner.md` changes, add the old file's sha256 to `KNOWN_OLD` in `selfedit/prompts.py` so installed copies upgrade. Every change ships with tests, a CHANGELOG line, the brief (`docs/brief.md`) kept current, and a push to `main`.

**Owner's way of working.** A student, beginner coder, Windows, speaks casually. Wants short direct answers for simple things and full material (PDFs, links) for big ones; plain words, no filler. Ask lots of questions before building (2 to 4 at a time, with a recommended option), then build one step at a time, test, push, and report briefly; don't repeat the missing-features list (`docs/missing.md` / `Prometheus-missing.pdf` has it). Nothing is hidden from suggestions (they decide), but risky things are labelled.
