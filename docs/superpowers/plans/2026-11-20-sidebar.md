# Sidebar Redesign and Microphone Button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude-style sidebar (actions, Projects with their chats, Recents, pages under More) and a microphone on/off button next to Stop all.

**Architecture:** The chat lists come from one small module (`prometheus/web/sidebar.py`) and one HTML partial fetched by HTMX
(`GET /api/v3/sidebar`), refreshed whenever chats change (a `sidebar-refresh` event). The page links stay in the DOM
(`#nav`) so Ctrl+1…0, the Ctrl+K palette and arrow-key navigation keep working; only Home and Tasks show, the rest sit
in a More popover. The mic button uses a new JSON route on the existing VoiceService.

**Tech Stack:** FastAPI, Jinja2, HTMX, vanilla JS, CSS tokens (tokens.css), pytest, Playwright (Chromium).

**Spec:** `docs/superpowers/specs/2026-11-20-sidebar-design.md`

## Global Constraints
- Colours only via `var(--…)` from tokens.css (test_colours_only_in_the_token_file).
- No browser `prompt()` for new dialogs (it may not show in the desktop window): use `<dialog>` like `#name-dialog`.
- Works at 360 px wide with no sideways scroll; the phone drawer shows the same sidebar.
- No page or feature removed; Ctrl+1…Ctrl+0 keep their current targets (Home 1, Agents 2, Chats 3, Projects 4, Skills 5,
  Tasks 6, Memory 7, Automations 8, System 9, Research 0).
- No new Settings options. Tests: `/home/user/venv314/bin/python -m pytest -q`; browser tests with
  `PROMETHEUS_CHROMIUM=/opt/pw-browsers/chromium`.
- Recents: 15 newest non-project chats, pinned first. Project: 8 newest chats. Projects in the trash are left out.

## Review Focus
- A chat title with HTML in it (`<b>x</b>`): shown as text, never as markup (Jinja autoescape; test in Task 1).
- A project with no chats: shows "+ New chat here" only, no empty gap (Task 1 test).
- Deleting the chat that is open: you land on the chat list and the sidebar no longer lists it (Task 2 browser test).
- Many chats (200): the sidebar renders only 15 recents + "Show all chats", no slowdown (Task 1 test).
- Voice not set up on this computer: no mic button (not a dead one) (Task 3 test).
